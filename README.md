# Arban CRM: desktop app (Windows)

The Arban CRM app for the Arban AI team. It opens the live CRM (crm.arbanai.co.uk) in its own window, runs Phonon-2 speech recognition on your computer, and adds a Ctrl+Space shortcut for Temujin, desktop notifications and a tray icon.

**You need the Arban team sign-in to use it.** This repository contains only the installer, not the CRM.

## Install

1. Download **[Arban-CRM-Setup.exe](https://github.com/akritp00-byte/arban-crm-desktop/releases/latest/download/Arban-CRM-Setup.exe)** (about 110 MB).
2. Run it. The installer isn't signed yet, so Windows may say "Windows protected your PC". Click **More info → Run anyway**.
3. In the app, click **Sign in with your browser**. Sign in to Cloudflare in your browser. When it asks **"Open Arban CRM?"**, tick **Always allow** and click **Open**.
4. Pick your profile on **"Who's using Arban CRM?"**.

## Speech recognition (optional)

To use Phonon-2 on your computer, open **Settings → Temujin → Speech recognition** and click **Set it up**. It's a one-off download of about 400 MB. Until it's set up, Temujin uses Whisper.
